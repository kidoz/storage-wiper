# Tutorials

Tutorials teach through a fixed sequence with a visible result. These exercises
do not wipe a real device.

| Tutorial | What you will learn | Prerequisites |
| --- | --- | --- |
| [Build and explore](build_and_explore.md) | Build the three executables and run simulated tests | A Linux development environment |
| [Inspect devices](inspect_devices.md) | Read disk listings and distinguish a disk from a partition | An installed application and helper |

For a task you already understand, use the [how-to guides](../how_to/README.md).
For design context, use [explanation](../explanation/README.md).
